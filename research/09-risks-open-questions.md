# 09 Risks and open questions

What could derail the engine replacement, how each risk is contained, and the questions the research program still has to answer.

_Accurate as of 2026-09-11 (branch chore/xlsx-hand-roll); the open-question statuses in §2 are as of 2026-09-27._

## 1. Risk register

Likelihood and impact are Low / Medium / High. "Owner" names the work package (WP) or document that carries the mitigation.

## 2. Open questions

| #   | Question                                                                                                                                                                                          | Answered by                                                                                                      | Status                                                                                                                                                                               |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | Does Excel accept a static `[Content_Types].xml` written first with a `<Default Extension="xml">` worksheet mapping, or must content types be exact and last?                                     | WP4 Excel oracle on the Phase A demo file (or on office-kit's streaming output, which decides the same question) | Answered: exact content types are written last and Excel accepts them (EC-ZIP-CONTENT-TYPES-LAST, run `phase-b-writer`)                                                              |
| 2   | Does Excel open a small workbook whose entries declare zip64 up front (version 4.5 plus extra field) when nothing exceeds 4 GiB?                                                                  | WP4, `hostile/` and `edge/` zip64 fixtures                                                                       | Answered: yes, when the local-header sizes are zero with bit 3 set (EC-ZIP64-LOCAL-SIZES-BIT3); SheetJS and Google Drive refuse it (EC-ZIP64-SMALL), hence `zip64: 'auto'` (ADR-002) |
| 3   | Are mixed `t="s"` and `t="inlineStr"` cells in one sheet accepted by every target viewer, and does Google Sheets keep them on import?                                                             | WP4 oracle plus the Google Sheets checklist                                                                      | Moot: inline strings are the default; Google Sheets imported both our goldens identically (`fixtures/golden/simple-excel/STEPS.md`)                                                  |
| 4   | Does `@office-kit/xlsx` stream without materializing when `minRow > 1` ("band queries materialize inflated worksheet" per its README), and does that matter for the multi-object `range: 4` read? | WP5 API mapping; workaround is iterating from row 1 and skipping                                                 | Moot: the ADR-008 addendum chose to build the library instead                                                                                                                        |
| 5   | Does `@office-kit/xlsx` (through fflate's async API) create `blob:` workers, which the MV3 CSP and the web `script-src` forbid?                                                                   | WP5 platform check under a CSP-enforcing page                                                                    | Moot: the ADR-008 addendum chose to build the library instead                                                                                                                        |
| 6   | What does `@office-kit/xlsx` throw for an encrypted workbook, and does the message contain `password-protected`?                                                                                  | WP5 with the encrypted hostile fixture (`SelectObjectAndFile.tsx:146` matches that substring)                    | Moot (answered in 10): its message ("Encrypted xlsx is not supported…") lacks `password-protected`, and 0.11 gave it for `.xls` too                                                  |
| 7   | Does `@office-kit/xlsx` decode `_xHHHH_` escapes and numeric character references in inline strings (its issue #131 is open on the latter as of 2026-09-04)?                                      | WP5 corpus parity run                                                                                            | Moot (answered in 10): office-kit does not decode `_xHHHH_` escapes                                                                                                                  |
| 8   | Native `CompressionStream` throughput in Chrome and Node on the M4, and whether the platform stream exposes a compression level                                                                   | WP3 first benchmark cell                                                                                         | Answered: about 135 MB/s in Node on the M4, and no compression level (06, ADR-005)                                                                                                   |
