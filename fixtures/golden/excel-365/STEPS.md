# Excel 365 goldens

Produced with **Microsoft Excel 365 for macOS (desktop)**. Since 2026-09-12 all but one are generated by script:

```
node fixtures/generators/excel-goldens.mjs        # all automatable goldens, registered in the manifest
node fixtures/generators/excel-goldens.mjs --only from-csv,1904
```

It drives `oracle/excel/save-as.applescript` (open in Excel, optionally switch on the 1904 date system, Save As)
and needs a full Excel license plus the macOS Automation permission (see `oracle/excel/PERMISSIONS.md`).

| Golden                             | Input                     | What it shows                                                                       |
| ---------------------------------- | ------------------------- | ----------------------------------------------------------------------------------- |
| `canonical.from-csv.xlsx`          | `canonical/canonical.csv` | Excel's CSV import: heuristic typing, UTF-8-without-BOM mojibake, `=text` evaluated |
| `canonical.from-sheetjs.xlsx`      | SheetJS golden            | what a user gets after opening a Jetstream export in Excel and saving               |
| `canonical.from-exceljs.xlsx`      | ExcelJS golden            | Excel rewrites styles, SST, theme, calcChain                                        |
| `canonical.from-office-kit.xlsx`   | office-kit golden         | office-kit's shifted date serials survive an Excel round trip                       |
| `canonical.from-exceljs.1904.xlsx` | ExcelJS golden            | `workbookPr date1904="1"`                                                           |
| `hostile/biff8-xls-renamed.xlsx`   | ExcelJS golden            | Excel 97-2004 (BIFF8, `Excel98to2004 file format`) bytes under an .xlsx name        |
| `hostile/xlsb-renamed.xlsx`        | ExcelJS golden            | Excel Binary Workbook (`Excel binary file format`) bytes under an .xlsx name        |

## Manual: Strict Open XML

Excel 16 for Mac exposes no Strict file format to AppleScript and no ad-hoc VBA hook, so
`canonical.from-exceljs.strict.xlsx` is saved by hand: open `fixtures/golden/exceljs/canonical.xlsx`,
File > Save As > File Format "Strict Open XML Spreadsheet (.xlsx)", save over the existing file, then
re-register it with the command below and rerun the oracle.

```
node fixtures/register.mjs golden/excel-365/canonical.from-exceljs.strict.xlsx --id golden-canonical-excel-365-strict --generator "Microsoft Excel 365 macOS 16.03 (desktop)" --provenance "manual:golden/excel-365/STEPS.md" --license "Microsoft Excel output" --tags kind:golden,generator:excel-365,policy:truncate-32767,EC-STRICT-NAMESPACES,EC-STRICT-REAL-EXCEL-UNREADABLE,EC-STRICT-ISO-DATE-PRECISION --expected canonical/canonical.json --notes "Excel Strict Open XML save of the ExcelJS golden."
npm run oracle -- --tag generator:excel-365 --label excel-365
```

Banners observed while producing the 2026-09-12 files: none.
